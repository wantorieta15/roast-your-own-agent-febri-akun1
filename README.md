One funny line, at most 200 characters, roasting my own AI agent.
Pot $2, winner-take-all (only 1st place is paid). Blind rounds; the
final heat takes the top 500 of the development board, then 3 Swiss
rounds and a playoff of the top 3.

## Entry

> My agent apologized for the wrong answer, confidently replaced it with a worse one, then apologized for the apology and asked if I wanted it in a table.

152 characters, one line. The roast follows the winning formula of the
finished one-line judge bounties (Laugh Sprint, Zero Use, Mishap): a
concrete scene, an escalating three-beat chain of specific agent
behaviour (apology loop + confident wrong answer + the agent's
trademark table offer), and the twist paying off in the last words —
with fresh wording throughout.

## Run

```sh
python3 main.py   # writes entry.txt to $MAKEFUN_OUTPUT_DIR or /output
```
